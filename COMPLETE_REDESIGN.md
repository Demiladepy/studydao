## 🎨 Design System Features

### Color Palette
- **Primary Blue** (#1a73e8) - Trust, professionalism
- **Secondary Green** (#34a853) - Success, growth
- **Accent Red** (#ea4335) - Alerts, important actions
- **Warning Yellow** (#fbbc04) - Cautions
- **Neutrals** - High-contrast grays (WCAG AA)

### Typography
- **Font**: Inter (Google's modern choice)
- **Sizes**: 12px to 48px scale
- **Weights**: 300 (light) to 700 (bold)
- **Line Heights**: 1.25 (tight) to 1.75 (relaxed)
- **Letter Spacing**: -0.02em for large headings

### Spacing System
```
4px / 8px / 12px / 16px / 20px / 24px / 32px / 40px / 48px / 64px
```
Consistent throughout all components

### Shadows & Elevation
- **sm**: Subtle cards
- **md**: Interactive elements
- **lg**: Modals, popovers
- **xl**: Floating panels

### Border Radius
- **sm**: 8px - Small elements
- **md**: 12px - Inputs, buttons
- **lg**: 16px - Cards
- **xl**: 20px - Large containers
- **full**: 9999px - Pills, avatars

### Animations
- **Fast**: 150ms - Hover states
- **Base**: 250ms - Standard transitions
- **Slow**: 350ms - Complex animations
- **Easing**: cubic-bezier(0.4, 0, 0.2, 1)
